# Homestead 🏠

Welcome to **Homestead**, a monorepo that unites my family’s business websites. This repository is designed to provide a centralized, simple, and organized space for my digital projects.

## Contents

- **`apps/copycraft/`**: Buchstabenfeder, the copywriting business of Sina Weichlein (Astro, Tailwind CSS).
- **`apps/office-hub/`**: Gabriela Bahr's bookkeeping and office services (Vite, React, Chakra UI).
- **`apps/vital-consultant/`**: Madita Bahr's sport and health consulting (Vite, React, Chakra UI).
- **`packages/components/`**: Shared Chakra UI components for the two Chakra apps.
- **`configs/`**: Shared TypeScript config.

## Why "Homestead"?

The name **Homestead** reflects a solid foundation for these projects, symbolizing stability, growth, and a place where everything thrives together. Just like a homestead is a home for a family, this repo serves as the digital home for my personal and family-related web projects.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/en)
- [volta.sh](https://volta.sh/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/fredericbahr/homestead.git
   cd homestead
   ```

2. Install dependencies and start the dev servers:
   ```bash
   npm install
   npm run dev
   ```
