# Buchstabenfeder

Website of **Buchstabenfeder**, the copywriting business of Sina Weichlein — live at [buchstabenfeder.de](https://buchstabenfeder.de).

Built with Astro, React islands, and Tailwind CSS. Started from the "Purrfectly Zen" Astro template.

## Development

```bash
npm run dev      # start the dev server
npm run build    # production build into dist/
```
